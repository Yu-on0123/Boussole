# 02 — Direction artistique

**Intention** : l'élève doit se sentir guidé par un instrument précis et honnête, qui montre son raisonnement.
**3 adjectifs** : précis · chaleureux · transparent.
**À éviter** : dégradé violet, glassmorphism décoratif, emojis-icônes, cartes toutes identiques, animation en boucle.

**Signatures (liées au concept « boussole + preuve »)**
1. **Le cadran** : sur la filière n°1, une aiguille pointe le score (0 gauche → 100 droite) avec compteur animé ; la rose des vents du hero se stabilise une seule fois.
2. **L'itinéraire** : l'arbre de preuve tracé comme un chemin en pointillés, nœuds règle/fait/test, apparition échelonnée.

**Style** : light-first « papier de carte » (`#f6f3ec`), dark complet (`#0a111e`) suivant le système + bouton. Primaire = encre ; **accent unique = laiton** (`#d99a2b`). Titres Newsreader, interface Geist, données Geist Mono (superfamille Geist + 1 serif = 2 familles).

**Hypothèses** : public = bacheliers béninois, souvent sur mobile ; démo portfolio ; texte français conservé tel quel ; la sortie des API reste inchangée.
